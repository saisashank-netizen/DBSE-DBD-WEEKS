# Student Records CRUD API

## Technologies
- Node.js
- Express.js
- MongoDB
- Mongoose

## Installation

npm install

## Run

npm run dev

## Server

http://localhost:3000

## Endpoints

POST /students
GET /students
GET /students/:id
PATCH /students/:id
DELETE /students/:id

## Database

mongodb://127.0.0.1:27017/student_records
